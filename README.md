**KH//OS** is an interactive, operating-system-inspired portfolio built to transform the traditional portfolio experience into something more immersive.

Instead of scrolling through static sections, users interact with a desktop environment — opening applications, navigating windows, exploring projects, and discovering the developer behind the system.

## `08 // APPLICATION BEHAVIOR`

All applications operate inside the KH//OS window environment.

```text
┌───────────────────────────────────────────────────┐
│                 WINDOW SYSTEM                   │
├───────────────────────────────────────────────────┤
│                                               │
│   OPEN       → Launch application              │
│   FOCUS      → Bring window to foreground      │
│   MINIMIZE   → Send window to Dock            │
│   RESTORE    → Return window to desktop        │
│   MAXIMIZE   → Expand window                   │
│   RESIZE     → Adjust window dimensions        │
│   CLOSE      → Terminate window instance       │
│                                               │
└───────────────────────────────────────────────────┘
```

### Window Features

- Independent application windows
- Focus management
- Dynamic stacking using z-index
- Window dragging
- Resizing
- Minimize and restore
- Maximize and return
- Animated Dock transitions

---

## `09 // INTERACTION MODEL`

### Desktop

- Double-click an application icon to open.
- Drag windows to reposition them.
- Resize windows using their edges and corners.
- Use window controls to manage applications.

### Mobile

- Tap an application icon to open it.
- Applications adapt to the mobile viewport.
- Window dragging and resizing are disabled.
- Touch-friendly controls are provided.
